# Indian_Startup_Funding_Analysis-PowerBI
A Power BI project analyzing Indian startup funding trends to identify major industries, startup hubs, investors, and funding patterns.

## 📌 Project Overview
This project analyzes startup funding data across industries, cities, investors, and investment types to understand India's evolving startup ecosystem.

## 🎯 Objectives
* Analyze total startup funding
* Identify top-funded industries and cities
* Understand investor activity
* Track funding trends over time
* Analyze investment types

## 📊 Dataset

**Source:** Kaggle — Indian Startup Funding Dataset
* Key fields include - Startup Name, Industry, City, Investors, Investment Type, Funding Amount, and Funding Date.

## 🛠️ Tools Used
* Microsoft Power BI
* DAX
* Data Visualization

## 📈 Dashboard KPIs
* Total Funding Raised
* Total Startups Funded
* Total Investors
* Average Funding per Startup
* Active Startup Cities
* Funding Growth Rate

## 💡 Key Insights
* $28.64Bfunding across 1,156 startups and 1,137 investors
* $24.78M** average funding per startup
* Bangalore, Mumbai, and Gurgaon are major startup hubs
* E-commerce and Consumer Internet receive significant funding
* Private Equity and Seed funding are prominent investment types
* Funding showed strong growth from 2016–2019

## 🚀 Project Impact
*The dashboard provides a clear view of funding trends, leading sectors, startup hubs, and investor participation, supporting data-driven analysis of India's startup ecosystem.*
